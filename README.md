# 📈 E-commerce Financial Forecast Model (12-Month Projection)
![Dashboard Preview](./Screenshot%202026-04-10%20032044.png)

## 🎯 Project Overview
This is a professional 12-month financial projection model designed for e-commerce scaling. It provides deep insights into revenue trajectories, profitability, and customer acquisition costs.

## 🚀 Key Features & Insights:
*   **Revenue Growth Tracking:** Visualizes monthly trajectory from ₹10L to ₹17L+.
*   **Profitability Analysis:** Dynamically tracks Net Profit as the business reaches efficiency.
*   **Customer Acquisition (CAC):** Monitors the correlation between marketing spend and customer growth.
*   **Dynamic Dashboard:** Executive-level visual reporting for quick decision-making.

## 🛠️ Technical Skills Used:
*   **Advanced Excel:** Data Modeling & Complex Formulas.
*   **Financial Theory:** Revenue Forecasting & Unit Economics.
*   **Data Visualization:** Interactive Charting & Dashboard Design.
